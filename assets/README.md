# Put your own wallpapers here

This repository ships **only** `default.svg`, an original placeholder drawn for
this project. It contains no third-party artwork.

Drop your own JPG / PNG / WebP / AVIF / SVG files into this folder, then rebuild:

```sh
python3 tools/build-client.py
```

The settings-row picker is generated by scanning this folder at build time, so
new files appear automatically, grouped by the part of the filename before the
first `-` (for example `nature-01.jpg` → group `Nature`). For custom labels and
groups, copy `wallpaper-catalog.example.json` to `wallpaper-catalog.json` and
edit it.

Files are served by DSH at `plugins/dsh-custom-wallpaper/assets/<file name>`.

> Do not commit copyrighted game art, stock photos, or downloaded wallpapers to
> a public repository. See the top-level README for details.
